# Joyería Dala - Plataforma Web (SPA)

Módulo de software para el catálogo digital e interfaz interactiva de **Joyería Dala**, desarrollado como evidencia de aprendizaje para el Servicio Nacional de Aprendizaje (SENA).

## Información de la Evidencia
* **Programa:** Tecnólogo en Análisis y Desarrollo de Software (ADSO)
* **Código de Evidencia:** GA7-220501096-AA3-EV01
* **Aprendiz:** Samuel Osorio

## Descripción Funcional
* Arquitectura basada en Single Page Application (SPA) con Vanilla JavaScript.
* Catálogo dinámico con filtros interactivos por categoría de joya y disponibilidad de inventario.
* Carrito de compras desplegable (Drawer) con cálculo automático de totales.
* Formulario de orden de pedido integrado con la API de WhatsApp para envío de solicitudes.
* Configuración de métodos de pago electrónicos en Colombia (Nequi, Daviplata, Bancolombia / PSE, Tarjetas de Crédito y Débito).

## Tecnologías Utilizadas
* **HTML5:** Estructura semántica de documentos.
* **CSS3:** Hojas de estilo adaptativas con CSS Grid, Flexbox y tipografía estandarizada.
* **JavaScript (ES6):** Manipulación dinámica del DOM y gestión del estado del carrito.
